PROMPT 2.3  —  Confidence Scorer & Auto-Resolver

confidence_scorer.py — expose:

  score_resolution(intent_result: dict, ast_diff_result: dict) -> float

  Logic:

    base_score = intent_result['confidence']

    if ast_diff_result['modified_functions'] has 0 items: penalty = 0.05

    if ast_diff_result has >3 modified_functions: penalty = 0.10

    if intent_result['compatible'] is True: bonus = 0.05

    final = clamp(base_score - penalty + bonus, 0.0, 1.0)

  Return the final float.



auto_resolver.py — expose:

  resolve(conflict: dict, intent_result: dict, score: float,

          github_repo, commit_sha: str) -> dict

    Write the winning code version to the file in-place

      - Both code versions

      - LLM reasoning

      - Confidence score

      - Tag both commit authors

    Return { 'action': 'escalated', 'score': score }

  If 0.60 <= score <= 0.85:

    Return { 'action': 'needs_review', 'score': score }
